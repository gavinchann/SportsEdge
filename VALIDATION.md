- Walk-forward run: 100 held-out games per league, five trained folds per league, three model predictions per game.

The report is generated by the commands in the README and is available locally at `runs/latest/report.json`. It is deliberately not committed as real-data evidence. No real-world predictive performance or profitability has been established. Remote CI results must be checked separately.
